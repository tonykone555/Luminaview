# Lumina View

Lumina View is the business-facing AI visibility and competitor-intelligence product in the Lumina ecosystem.

The current website includes:
- AI Visibility Score presentation
- competitor share-of-visibility
- buyer-intent query analysis
- done-for-you implementation packaging
- Prospect Engine preview builder
- client report structure
- personalized outreach generator
- production safeguards against invented competitor/ranking claims

## Run
Open `index.html` directly or deploy the repository as a static site.

## Production note
The front-end workflow is implemented. Real cross-platform visibility checks still require compliant data/provider connections before live competitor evidence can populate automatically.
